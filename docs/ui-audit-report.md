# Guaji AI 移动端UI审查报告

**审查日期：** 2026-07-21
**审查范围：** 全部13个页面 + 2个公共组件
**审查方式：** 实际截图 + 源码静态分析（模拟移动端视角）
**审查站点：** https://guajiguaji.top/

---

## 📌 全局问题（跨页面）

| # | 问题描述 | 严重程度 | 影响页面 |
|---|---------|---------|---------|
| G-01 | **Tawk.to 客服弹窗遮挡内容**：客服组件在移动端右下角弹出大型提示框（"Hi! How can we help?"）并显示4个快捷回复按钮，严重遮挡页面底部操作区域（按钮/输入框）。 | 🔴 严重 | Welcome、Login、Register 等所有页面 |
| G-02 | **浏览器标签闪烁**：Tawk.to 默认推送消息导致标签页标题出现 "1 new message" 反复闪烁，影响使用体验。 | 🔴 严重 | 全部页面 |
| G-03 | **Logo 不统一**：Splash Screen 使用 `school` 图标；Welcome/Landing 页使用纯渐变色方块；Login/Register 页仅显示小紫色圆点；三种形态不一致。 | 🟠 重要 | 全部页面 |
| G-04 | **中英文混用**：多个页面同时存在中文和英文文案（如场景标题全为英文、部分按钮/提示为英文），破坏产品一致性。 | 🟠 重要 | Discovery、GoalSetting、Goals 等 |
| G-05 | **暗模式入口缺失**：代码支持 dark mode，但除 Profile 页面的 "主题" 菜单项外，无任何可见的暗模式切换开关，且该菜单点击无效。 | 🟡 一般 | 全部页面 |
| G-06 | **导航死角**：Checkin、Conversation、History、GoalSetting、Onboarding 等页面无底部导航栏，用户完成操作后需依赖浏览器返回键，移动端体验差。 | 🟠 重要 | 上述5个页面 |
| G-07 | **返回按钮路径不统一**：部分页面"返回"按钮跳转至 `/`（Landing），另一些跳至 `/discovery` 或 `/profile`，逻辑不一致。 | 🟡 一般 | Login、Register、Checkin 等 |
| G-08 | **不存在的路由被引用**：Profile 菜单包含 `/settings`（账户设置）和 `/notifications`（通知）两个路由，但 App.js 中未注册这两个路由，点击后会跳转至首页而非目标页。 | 🔴 严重 | Profile |

## 页面2：欢迎页 Welcome（/welcome）

**截图说明：** 页面右下角可见 Tawk.to 客服弹窗明显遮挡操作区域

| # | 问题描述 | 严重程度 |
|---|---------|---------|
| W-01 | **Logo 为纯色方块，无品牌识别度**：Logo 区域显示为纯渐变色矩形（`linear-gradient(135deg, #667eea, #764ba2)`），无任何文字或图标，品牌识别度极低。 | 🟠 重要 |
| W-02 | **语言选择器位置不合理**：语言下拉框放置在页面最底部，用户很难发现；且仅改变引言文字语言，UI 其余部分不变，功能效果令人困惑。 | 🟠 重要 |
| W-03 | **"或继续使用" + 图标含义不明**：`account_circle` 图标在此语境下让用户不知道点击后会发生什么，且该按钮无任何点击事件绑定，属于无效元素。 | 🟡 一般 |
| W-04 | **Tawk.to 弹窗覆盖底部按钮**：客服弹窗遮挡"创建账户"和"登录"按钮，用户需先关闭弹窗才能操作，影响转化率。 | 🔴 严重 |
| W-05 | **引言文字字体偏小且颜色浅**：引言区域使用 `text-slate-500 text-sm italic`，在移动端强光环境下可读性差。 | 🟡 一般 |
| W-06 | **垂直空白过多**：页面内容集中于顶部和底部，中间留有大量空白，在短屏手机上内容挤压，在长屏手机上则显得空旷。 | 🟡 一般 |

| # | 问题描述 | 严重程度 |

| L-04 | **Tawk.to 弹窗遮挡页面下半部分**：客服弹窗出现在登录表单旁边，干扰用户填写表单。 | 🔴 严重 |

## 页面9：个人中心 Profile（/profile）

| # | 问题描述 | 严重程度 |
|---|---------|---------|
| P-01 | **每周进度图表使用硬编码数据**：`weeklyData` 数组使用固定的 `height` 百分比值（40%、25%、90% 等），与用户真实学习数据完全无关，具有误导性。 | 🔴 严重 |
| P-02 | **"估计词汇" 数据虚假**：词汇数按 `totalSessions × 50` 计算，这不是真实词汇量，属于误导性数据展示。 | 🟠 重要 |
| P-03 | **成就系统全部硬编码**：5个成就（词汇大师、10天连续、对话达人等）完全静态，无论用户实际行为如何，前3个永远显示为"已解锁"，后2个永远"未解锁"。 | 🔴 严重 |
| P-04 | **菜单包含不存在的路由**："账户设置"（/settings）和"通知"（/notifications）点击后会跳到 Landing 页（App.js 通配符重定向），用户体验极差。 | 🔴 严重 |
| P-05 | **"主题"菜单项点击无效**：`{ icon: 'palette', label: '主题', value: '深色' }` 无 `path` 属性，点击不会触发任何操作，却显示为可点击样式。 | 🟠 重要 |
| P-06 | **设置图标（右上角）无功能**：顶部右侧的 settings 图标按钮无任何点击处理函数，属于无效UI元素。 | 🟡 一般 |
| P-07 | **Profile 同时存在顶部返回和底部导航**：Profile 有返回按钮（→/discovery）和底部导航栏，两套导航并存，信息架构混乱。 | 🟡 一般 |

## 组件A：底部导航 BottomNav

| # | 问题描述 | 严重程度 |
