- `python3 scripts/sdlc.py validate`：SDLC gate: clean。

- Landing 初始空价格即显示不可用；一次请求失败后无重试；卸载时 abort 的 catch 仍写状态。Subscription 未检查 HTTP 状态且失败变空列表。后端每次公开目录请求都会读取 Stripe，未见目录缓存。上述是源码缺陷/风险，尚不能确认为生产接口间歇失败的根因。
