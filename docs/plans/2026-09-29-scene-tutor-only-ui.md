# Scene Theater：仅导师回复呈现教学内容

用户最终要求取消所有建议卡和澄清卡，替代之前“只去掉普通卡文本框”的界面方案。
建议表达、示范、纠错说明和澄清问题都直接出现在导师的文字/语音回复中，学生继续录音回答。

## 实现

- 删除 `ExpressionFeedback` 组件、卡片发送分支和专用卡片合法性函数。
- `expression_feedback` WS 事件作为兼容元数据忽略，不进入对话消息列表。
  恢复的旧类型消息也不渲染，不会变成空白卡片或学生气泡。
- 保留 `teaching_state` 的输入 ID / 任务 / 非零代次校验；等待、失败与重试状态仍可用。
- 移除点选发送入口后，把已中断响应 ID 的登记放到录音开始处，继续拒绝旧文本及 PCM。
- 场景提示词不再假设用户能看到独立卡片，要求解释、一个实用示范或澄清问题直接放入导师回复，
  不再指示点选句子或编辑文本框。新链路现有 `ai_message` 本来就包含校验后的同一口播稿，
  无需把独立点评追加成未被导师实际说出的内容。
